# GROUNDING.md retirement ledger

This ledger records where every paragraph and list item of the frozen `GROUNDING.md` goes when the file is retired. The frozen text is `git show ebbf8f94:GROUNDING.md`, which has 3,430 lines. Its rules are in `docs/designs/bundle-isolation-docs.md`, under "Retiring the grounding file" and "What the ledger adds to the table above".

- **Lines.** Each row names a range of source lines, `N` or `N–M`. A row that takes only part of a line names that part in parentheses: `(clause "…")`, or `(rest)` for what the clause rows on the same line leave. The rows cover lines 1–3,430 with no gap.
- **Shared lines.** A line that holds two subjects appears in both rows.
- **Blank lines and headings** belong to the row that follows them.
- **Outcome.** Each row has exactly one of three:
  - **moved**: the destination column names the document that takes the text.
  - **obsolete**: the column cites the `file:line` at HEAD that shows the code does otherwise or the thing no longer exists.
  - **history**: the column cites the dated record that holds the text. A history row's text goes into no living document (OD57).
- **Destinations and evidence** are full repository paths, cited at HEAD of `feat/bundle-isolation`, `e7be5775`. The root `AGENTS.md` is `AGENTS.md`. "Note:" in a moved row is a fact the writer must state from the code, not from the frozen text.
- **Markers.** **Verbatim** marks text that moves word for word into the root `AGENTS.md`. **Reworded** marks the two whose object is this file, HC-001 and CP-005: their object is reworded to name the root `AGENTS.md`, and nothing else in them changes.
- **Status.** Every row starts `open`. Only the reviewer of the destination document closes a row, never its writer.
