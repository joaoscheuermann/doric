Estados lado a lado no canvas

Os mesmos componentes do canvas de hoje, com uma diferença: o preview passa a ter vários frames, um por story, cada um com o nome em cima. O resto não muda: barra de comandos flutuante, painel "estrutura", pinos, grade de pontos e node quadrado. Os dados são de exemplo, de um CheckoutCard.stories.tsx fictício.

Janela do canvas

Clique num frame na estrutura ou no nome dele no canvas para dar zoom. O botão novo 4 estados na barra de comandos escolhe os estados, o tema e o layout. Arraste o fundo para mover.

Node na conversa

O node continua quadrado, com o mesmo cabeçalho e o mesmo rodapé de zoom. Ele abre ajustado à grade inteira, e o nome do frame aparece na linha do comentário.

  • O frame é a página do preview de hoje, repetida: o mesmo mount, o mesmo CSS e a mesma margem de 8px, e cada um com o fundo do próprio tema.
  • A estrutura vira um painel flutuante, com a mesma borda, raio, fundo e sombra da barra de comandos. Ela ganha um nível: os frames ficam no topo, com os elementos de cada um embaixo, e o olho esconde um frame inteiro, igual faz com um elemento.
  • Um controle novo só: o menu 4 estados na barra de comandos, no mesmo padrão do rev n/m. No node não entra nada novo além do "· 4 estados" no cabeçalho.
  • O frame faz parte da identidade do pino. O mesmo CheckoutCard.tsx:58 existe em todos os frames.
